Who uses ftc-embeds

Per website: loads of the iframes and of the script from ftc-embeds.com, and calls to the embeds API, which is how sites that install the npm package show up. Counted from the Referer header the browser sends; no IP addresses or cookies are stored.

Websites

Iframe loads are counted on every visit. Script loads are a lower bound: Cloudflare serves cached copies of the script without asking the server. Visits within 5 minutes of each other may count once. API calls are the requests the widgets make for their data (one or two per widget per visit, plus refreshes during a competition); the iframes' own calls aren't counted again, but sites using the script tag show up there too. "(no referrer)" means the browser didn't say which site it came from, the embed was opened directly, or the API was called from a server.
